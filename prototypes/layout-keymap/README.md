# Layout and keymap prototype

Throwaway. Answers wayfinder ticket 06: what should the triage screen look like and how should the keys feel. Fake data, no network, nothing persisted. Do not grow this into the app.

Run:

```
cargo run --manifest-path prototypes/layout-keymap/Cargo.toml
```

Three layout variants, switched with `[` and `]` or `F1` to `F3`. The yellow bar at the bottom is the prototype switcher, not part of the design. Press `?` for the keymap.
